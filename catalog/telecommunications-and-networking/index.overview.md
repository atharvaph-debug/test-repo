# Telecommunications & Networking

Identifiers, routing pathways, and quality parameters that drive cellular and data networking services.

| Path | Title | Type | Description |
|------|-------|------|-------------|
| catalog/telecommunications-and-networking/access-point-name | Access Point Name | file | The identifier presented by a device to select the target packet data network and routing gateway for a data session. |
| catalog/telecommunications-and-networking/customer-churn | Customer Churn | file | The percentage of the subscriber base that deactivates during a given quarter, driven by price, network quality, or competitor offers. |
| catalog/telecommunications-and-networking/international-mobile-subscriber-identity | International Mobile Subscriber Identity | file | A globally unique identifier stored on a SIM card to identify and authenticate a subscriber within mobile networks. |
| catalog/telecommunications-and-networking/number-portability | Number Portability | file | The regulatory-mandated process enabling subscribers to retain their phone number when switching telecom carriers. |
| catalog/telecommunications-and-networking/quality-of-service | Quality of Service | file | Mechanisms and rules used to prioritize network traffic to meet strict latency, packet loss, and jitter targets. |
| catalog/telecommunications-and-networking/voice-over-lte | Voice over LTE | file | Technology that carries voice calls as packet data over LTE networks with high priority treatment to ensure acceptable quality. |
