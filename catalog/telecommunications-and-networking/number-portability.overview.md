# Number Portability Overview

Number Portability refers to the capability and process that allows telecommunications subscribers to retain their existing phone numbers when transferring between different carriers. This process enables customers to move their current phone number to a new service provider.

## Key Terminology and Aliases

This capability is known by several names, all referring to the same underlying concept. For accurate metadata enrichment and consistency across systems and documentation, it is crucial to recognize these as synonyms:
*   **Porting:** A common, shortened term for the process.
*   **LNP (Local Number Portability):** Specifically refers to the portability of local telephone numbers.
*   **MNP (Mobile Number Portability):** Specifically refers to the portability of mobile telephone numbers.
*   **Local Number Portability:** The full term for LNP.
*   **Mobile Number Portability:** The full term for MNP.

All these terms describe the same capability, which is regulated by industry standards to ensure seamless transitions for subscribers switching providers while keeping their established numbers.
