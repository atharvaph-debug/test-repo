# Risk, Compliance & Security

Terminology, processes, and filings associated with credit risk profiling and financial crime compliance.

| Path | Title | Type | Description |
|------|-------|------|-------------|
| catalog/risk-compliance-and-security/anti-money-laundering | Anti-Money Laundering | file | Broad transaction monitoring designed to identify patterns inconsistent with expected behavior and support suspicious activity reporting. |
| catalog/risk-compliance-and-security/credit-risk-score | Credit Risk Score | file | A quantified estimate of a borrower's default probability, evaluated using repayment history, current exposure, and leverage or income. |
| catalog/risk-compliance-and-security/know-your-customer | Know Your Customer | file | The process of verifying identity, establishing beneficial ownership for non-individual entities, and assigning a risk rating. |
