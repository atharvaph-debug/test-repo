# Metadata Enrichment Engine Overview

The Metadata Enrichment Engine (MEE), also known as metadata-enricher, is a core framework designed to automatically append semantic tags, classifications, and lineage details to ingestion pipelines. It serves as a crucial component for enhancing metadata quality and discoverability within data systems.
