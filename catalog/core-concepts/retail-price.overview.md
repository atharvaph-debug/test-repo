# Retail Price Overview

Retail Price represents the advertised catalog price for a product before any discounts are applied. This value indicates the initial public price set for an item.

## Key Features

The Retail Price is stored in the `products.retail_price` column. It serves as the standard price at which a product is initially offered to customers, distinct from the `Cost` (the wholesale price paid by the company) and the `Sale Price` (the actual price a customer pays after any discounts, which is used for revenue calculations).
