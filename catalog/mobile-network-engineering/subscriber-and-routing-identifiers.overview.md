# Subscriber and Routing Identifiers Overview

Subscriber and Routing Identifiers are critical network identifiers used to route data sessions correctly and authenticate subscriber SIMs. These identifiers play a fundamental role in mobile network operations, ensuring that devices can access the correct services and that subscribers are properly recognized.

## Key Identifiers

### Access Point Name (APN)
The **Access Point Name (APN)** is an identifier presented by a device that instructs the core network on which gateway to use for routing a data session. For example, it differentiates between routing to the public internet versus an internal IMS voice signaling APN.

### International Mobile Subscriber Identity (IMSI)
The **International Mobile Subscriber Identity (IMSI)** is a globally unique identity provisioned on the SIM card. It is utilized for subscriber recognition and authentication, both domestically and when roaming. Loose terminology like "SIM identity" should be standardized to "IMSI" in documentation.
