# Risk and Compliance

Metadata properties and processes tracking borrower risk and financial-crime regulatory compliance.

| Path | Title | Type | Description |
|------|-------|------|-------------|
| catalog/risk-and-compliance/credit-risk-score | Credit Risk Score | file | A quantified estimate of borrower default likelihood calculated using repayment history, current exposure, and leverage. |
| catalog/risk-and-compliance/financial-crime-compliance | Financial Crime Compliance | file | A collection of identity verification, continuous behavioral transaction monitoring, and regulatory filing workflows to mitigate financial crime. |
