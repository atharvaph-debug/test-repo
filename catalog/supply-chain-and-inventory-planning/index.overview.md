# Supply Chain and Inventory Planning

Formulas, classifications, and structural entities governing warehouse networks, material bills, and logistical replenishment flows.

| Path | Title | Type | Description |
|------|-------|------|-------------|
| catalog/supply-chain-and-inventory-planning/bill-of-materials | Bill of Materials | file | The hierarchical tree structure detailing component sub-assemblies and specific quantity recipes required to manufacture a finished parent SKU. |
| catalog/supply-chain-and-inventory-planning/reorder-point | Reorder Point | file | The automated inventory threshold calculated from daily demand, lead times, and safety buffers that triggers a replenishment order execution. |
| catalog/supply-chain-and-inventory-planning/safety-stock | Safety Stock | file | The buffer inventory held above anticipated baseline demand to protect supply flows from demand spikes and lead-time variability. |
| catalog/supply-chain-and-inventory-planning/stock-keeping-unit | Stock Keeping Unit | file | The granular, internal identifier representing a distinct sellable product variant at which inventory levels and location balances are tracked. |
