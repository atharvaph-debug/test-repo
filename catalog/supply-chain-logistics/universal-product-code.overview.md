# Universal Product Code Overview

A Universal Product Code (UPC), also known as a Global Trade Item Number (GTIN), is an external, globally registered barcode standard primarily used for retail scanning. It serves as an external identifier for products, distinguishing it from internal inventory management systems.

## Key Concepts

*   **Definition**: The UPC/GTIN is an external barcode standard assigned from a global registry, designed for retail scanning purposes.
*   **External vs. Internal Identifier**: While a Stock Keeping Unit (SKU) is an internal identifier that remains within a company's systems, the UPC/GTIN is an external identifier.
*   **Relationship to SKU**: The UPC/GTIN is stored as an attribute pointing to a specific SKU. It's critical to understand that a single product can map to several SKUs over its lifecycle. Treating a UPC/GTIN and an SKU as identical can lead to double-counting errors within inventory systems.
