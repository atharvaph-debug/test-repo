# Supply Chain & Logistics

Inventory identifiers, structured bill of materials data, and mathematical parameter calculations governing replenishment.

| Path | Title | Type | Description |
|------|-------|------|-------------|
| catalog/supply-chain-logistics/bill-of-materials | Bill of Materials | file | The hierarchical, engineering-controlled structured list of components and sub-assemblies needed to produce a finished SKU. |
| catalog/supply-chain-logistics/reorder-point | Reorder Point | file | An automated ERP replenishment system trigger calculated mathematically based on demand, lead times, and safety stock. |
| catalog/supply-chain-logistics/stock-keeping-unit | Stock Keeping Unit | file | The central internal identifier for a distinct, sellable product variant representing size, color, and pack configurations. |
| catalog/supply-chain-logistics/universal-product-code | Universal Product Code | file | An external, globally registered barcode standard used for retail scanning and mapped as an attribute to internal SKUs. |
