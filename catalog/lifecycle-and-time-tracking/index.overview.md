# Lifecycle and Time Tracking

Calculations and statuses capturing the progression of items through shipping and return phases.

| Path | Title | Type | Description |
|------|-------|------|-------------|
| catalog/lifecycle-and-time-tracking/processing-time | Processing Time | file | The cycle-time calculated as the difference between the shipped timestamp and the creation timestamp. |
| catalog/lifecycle-and-time-tracking/return-latency | Return Latency | file | The cycle-time representing the delay between item delivery and customer return. |
| catalog/lifecycle-and-time-tracking/transit-time | Transit Time | file | The cycle-time calculated as the difference between the delivery timestamp and the shipped timestamp. |
