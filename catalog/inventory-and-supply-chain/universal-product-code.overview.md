# Universal Product Code Overview

Universal Product Code (UPC), also known as Global Trade Item Number (GTIN), refers to external barcode standards utilized for retail scanning. These standards are managed by a global registry.

## Key Features

*   **External Identifier**: UPCs/GTINs serve as external barcode standards specifically designed for retail scanning operations.
*   **Global Management**: They are overseen by a global registry.
*   **Relationship to SKUs**: Within internal systems, UPCs/GTINs are stored strictly as attributes. They are mapped back to internal Stock Keeping Units (SKUs), which are the core internal identifiers for distinct, sellable product variants. It is important to note that UPCs/GTINs are not interchangeable with SKUs.
