# Inventory & Supply Chain

Systems, metrics, and parameters governing physical inventory, demand planning, and logistics operations.

| Path | Title | Type | Description |
|------|-------|------|-------------|
| catalog/inventory-and-supply-chain/bill-of-materials | Bill of Materials | file | The structured hierarchical recipe linking finished goods to component parts and sub-assemblies. |
| catalog/inventory-and-supply-chain/lead-time | Lead Time | file | The dynamic elapsed duration from placing a purchase order to when goods are received, inspected, and posted as available. |
| catalog/inventory-and-supply-chain/reorder-point | Reorder Point | file | The system-calculated inventory level that automatically triggers replenishment purchase orders. |
| catalog/inventory-and-supply-chain/safety-stock | Safety Stock | file | Extra inventory buffer held to protect service levels against demand and lead-time variability. |
| catalog/inventory-and-supply-chain/stock-keeping-unit | Stock Keeping Unit | file | The core internal identifier for a distinct, sellable product variant used to manage demand forecasting, stock holding, and replenishment. |
| catalog/inventory-and-supply-chain/supplier-scorecards | Supplier Scorecards | file | Performance ratings based on delivery, quality, and pricing metrics used to distribute purchasing volume. |
| catalog/inventory-and-supply-chain/universal-product-code | Universal Product Code | file | External barcode standards assigned for retail scanning and mapped back as attributes to internal SKUs. |
