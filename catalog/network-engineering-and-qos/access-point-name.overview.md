# Access Point Name Overview

The Access Point Name (APN), also known by its alias APN, is an identifier presented by a device to route data sessions through specific gateways. It serves a crucial role in directing network traffic based on its configuration.

## Definition and Purpose

An Access Point Name (APN) functions as a network identifier that a device uses to establish a data connection. It dictates how a data session is routed through the network, typically specifying the external network with which the device communicates (e.g., the internet or a private network). Examples include a "public-internet APN" for general internet access and an "internal IMS APN" for connecting to IP Multimedia Subsystem services within a carrier's network.

## Classification

The Access Point Name (APN) is categorized as a Telemetry Key, indicating its importance in network monitoring and data collection.
