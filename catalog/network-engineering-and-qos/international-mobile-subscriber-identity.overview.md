# International Mobile Subscriber Identity Overview

The International Mobile Subscriber Identity (IMSI) is a globally unique identifier provisioned on a SIM card, representing a specific mobile subscriber. It serves as a fundamental identifier in mobile networks, often referred to by the alias "SIM identity."

## Key Features

The IMSI is a critical identifier within network telemetry and metadata schemas. It is explicitly identified as the formal key to which the looser term "SIM identity" should be mapped for consistency and accuracy in data systems. This mapping ensures that all references to a subscriber's SIM-based identity converge to the standardized IMSI.

## Aliases

*   IMSI
*   SIM identity
