# Metadata Enrichment Service Overview

The Metadata Enrichment Service is a tool classified under Metadata Extraction Tools. It functions by enriching documents through the extraction of various metadata types, including keywords, entities, and categories.

## Aliases

This service is also known by its aliases: `mes` and `metadata-enrichment`.

## Key Features

The primary function of the Metadata Enrichment Service is to enrich documents by extracting and adding metadata. Specifically, it can extract and provide:
*   Keywords
*   Entities
*   Categories
