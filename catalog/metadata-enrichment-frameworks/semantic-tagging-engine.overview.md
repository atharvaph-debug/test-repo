# Semantic Tagging Engine Overview

The Semantic Tagging Engine (also known as STE or semantic-tagger) is a metadata enrichment framework designed to analyze dataset contents. Its primary function is to apply standardized semantic tags and classification labels to datasets. This process enhances metadata by adding structured, meaningful descriptors derived from the content itself, aiding in discovery and organization.
