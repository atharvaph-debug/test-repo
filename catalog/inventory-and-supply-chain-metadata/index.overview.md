# Inventory and Supply Chain Metadata

Attributes and planning logic governing manufacturing recipes, distribution networks, and fulfillment centers.

| Path | Title | Type | Description |
|------|-------|------|-------------|
| catalog/inventory-and-supply-chain-metadata/bill-of-materials-specification | Bill of Materials Specification | file | Multi-level hierarchical component definition mapping finished goods to their raw materials and sub-assemblies. |
| catalog/inventory-and-supply-chain-metadata/inventory-replenishment-parameters | Inventory Replenishment Parameters | file | Planning variables that configure order triggers, lead-time variances, and buffer inventory rules across DCs. |
| catalog/inventory-and-supply-chain-metadata/stock-keeping-unit-tracking | Stock Keeping Unit Tracking | file | Internal identifiers and external barcode standard mapping rules used to run inventory, cycle counts, and logistics routing. |
