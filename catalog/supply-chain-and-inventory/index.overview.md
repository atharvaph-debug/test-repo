# Supply Chain & Inventory Management

Rules, definitions, and mathematical structures for material resource planning, replenishment, and warehouse operations.

| Path | Title | Type | Description |
|------|-------|------|-------------|
| catalog/supply-chain-and-inventory/bill-of-materials | Bill of Materials | file | The authoritative hierarchical specification listing components and assemblies needed to construct a finished product. |
| catalog/supply-chain-and-inventory/reorder-point | Reorder Point | file | The automated stock inventory level that triggers a purchase requisition to replenish product supplies. |
| catalog/supply-chain-and-inventory/safety-stock | Safety Stock | file | The extra inventory buffer held above baseline demand to prevent stockouts from demand surges and supply delays. |
| catalog/supply-chain-and-inventory/stock-keeping-unit | Stock Keeping Unit | file | The internal foundational identifier representing a unique, sellable product variant across inventory networks. |
