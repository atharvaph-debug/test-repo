# Supply Chain and Inventory

Core metadata, planning parameters, and operational rules for inventory and supply chain systems.

| Path | Title | Type | Description |
|------|-------|------|-------------|
| catalog/supply-chain-and-inventory/bill-of-materials | Bill of Materials | file | The authoritative, engineering-controlled specification that translates a finished-good SKU into its component parts for downstream procurement. |
| catalog/supply-chain-and-inventory/logistics-network-topology | Logistics Network Topology | file | A modeled graph of independent, inventory-holding nodes comprising regional and forward distribution centers. |
| catalog/supply-chain-and-inventory/reorder-point | Reorder Point | file | The calculated inventory level that automatically triggers a purchase order based on daily demand, lead times, and safety stock. |
| catalog/supply-chain-and-inventory/safety-stock | Safety Stock | file | Extra buffer inventory carried to absorb demand spikes or lead-time variability, structured by SKU velocity class. |
| catalog/supply-chain-and-inventory/stock-keeping-unit | Stock Keeping Unit | file | An internal identifier that serves as the central hub linking engineering, planning, procurement, and warehouse operations. |
| catalog/supply-chain-and-inventory/supplier-scorecard | Supplier Scorecard | file | A structured, periodically refreshed rating aggregating on-time delivery, quality, and price competitiveness used to allocate order volume. |
