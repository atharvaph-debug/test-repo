# Supply Chain and Inventory

Operational concepts, infrastructure, and formulas for product development, warehouse operations, and inventory planning.

| Path | Title | Type | Description |
|------|-------|------|-------------|
| catalog/supply-chain-and-inventory/bill-of-materials | Bill of Materials | file | A structured engineering specification detailing the exact components, sub-assemblies, and quantities required to manufacture a single finished SKU. |
| catalog/supply-chain-and-inventory/distribution-centers | Distribution Centers | file | Tiered physical fulfillment nodes in the logistics network routing inventory from suppliers to demand centers. |
| catalog/supply-chain-and-inventory/reorder-point | Reorder Point | file | The designated inventory level that triggers automated replenishment based on safety stock, average daily demand, and lead times. |
| catalog/supply-chain-and-inventory/stock-keeping-unit | Stock Keeping Unit | file | The core internal identifier used to track unique sellable product variants at the individual size, color, and packaging level. |
| catalog/supply-chain-and-inventory/supplier-performance-scorecarding | Supplier Performance Scorecarding | file | An evaluation system tracking supplier on-time delivery %, quality metrics, and price competitiveness. |
