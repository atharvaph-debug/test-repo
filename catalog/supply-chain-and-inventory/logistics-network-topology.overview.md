# Logistics Network Topology Overview
The Logistics Network Topology describes the structure of a supply chain network. It is modeled as a graph of independent, inventory-holding nodes, which typically comprise regional and forward distribution centers, rather than operating as a single unified stock pool. This concept is also referred to as a "two-tier network architecture".

## Key Characteristics
The logistics network is explicitly modeled as a graph of independent, inventory-holding nodes, in contrast to a single unified stock pool. This architectural choice defines how inventory is distributed and managed across regional and forward distribution centers.
