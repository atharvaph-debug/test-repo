# Subscriber Identity and Network Sessions

Identifiers and routing parameters that govern subscriber sessions and system authentication.

| Path | Title | Type | Description |
|------|-------|------|-------------|
| catalog/subscriber-identity-and-network-sessions/access-point-name | Access Point Name | file | A network identifier presented by a device during session establishment that specifies the packet data network, gateway, policies, and services applied to a session. |
| catalog/subscriber-identity-and-network-sessions/international-mobile-subscriber-identity | International Mobile Subscriber Identity | file | A globally unique identifier of a subscriber provisioned onto the physical SIM card, used for network authentication, roaming, and data logging. |
