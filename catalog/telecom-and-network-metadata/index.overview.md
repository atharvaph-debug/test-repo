# Telecom & Network Metadata

Metadata standards, identifiers, and configuration rules governing network provisioning, performance metrics, and subscriber operations.

| Path | Title | Type | Description |
|------|-------|------|-------------|
| catalog/telecom-and-network-metadata/access-point-name | Access Point Name | file | The protocol identifier that determines which packet data gateway, network segment, and policy set a data session uses. |
| catalog/telecom-and-network-metadata/international-mobile-subscriber-identity | International Mobile Subscriber Identity | file | The globally unique identifier of a mobile subscriber, written to the SIM card and registered in subscriber databases for home and roaming authentication. |
| catalog/telecom-and-network-metadata/voice-over-lte | Voice-over-LTE | file | A high-priority service that routes conversational voice calls as packets over the LTE network using IMS. |
