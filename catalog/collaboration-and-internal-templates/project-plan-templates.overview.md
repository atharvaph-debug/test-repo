# Project Plan Templates Overview

Project Plan Templates, also known as `template-project-plan` or `project-planning`, provide a structural formatting framework that defines milestones, goal alignments, team responsibilities, and scoped task boundaries for projects. These templates are designed to standardize project planning metadata, facilitating consistent enrichment and management of project information.

## Key Features

The template standardizes various aspects of project planning through structured metadata:
*   **Roles**: Defines specific project roles including Driver, Approver, Contributors, and Informed.
*   **Objectives**: Standardizes how project objectives are documented.
*   **Milestones**: Provides a framework for defining and tracking project milestones.
*   **Problem Statement**: Requires a structured "Problem statement" with a specific format: "We think X will do Y, and we'll know we've succeeded if Z". This ensures clarity and measurability for the problem being addressed.
*   **Scope Definition**: Enforces a structured definition of project scope, which is divided into three categories: "Must have", "Nice to have", and "Not in scope". This helps in clearly delineating project boundaries and priorities.
