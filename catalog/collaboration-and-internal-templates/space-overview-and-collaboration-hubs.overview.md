# Space Overview & Collaboration Hubs Overview

Space Overview & Collaboration Hubs automatically aggregates metadata on document portals to trace active contributors and capture recently updated files. It is also known by the aliases `confluence-demo` and `space-overview`.

## Key Features

This entry describes a Confluence space overview page designed to provide metadata enrichment for collaboration. It automatically updates and displays key information based on system-level metadata whenever space content is modified. The primary metadata tracked and displayed includes:

*   **Recently updated content**: A list of files or pages that have undergone recent modifications.
*   **Contributors**: A list of active individuals who have modified content within the space.

This functionality relies on the system-level metadata within Confluence to ensure these lists are current and accurate, providing insights into content activity and participation.
