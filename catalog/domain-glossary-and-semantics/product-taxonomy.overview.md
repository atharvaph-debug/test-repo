# Product Taxonomy Overview

The Product Taxonomy, also known as `product-hierarchy`, is a three-level classification system designed to organize sellable product variants (SKUs). It provides a structured hierarchy for product metadata enrichment, making it easier to categorize and understand individual products.

## Key Features

The taxonomy organizes products into a hierarchical structure:

*   **Department**: This is the broadest level of classification. Examples include 'Men' and 'Women'.
*   **Category**: This level defines the product type. For instance, 'Jeans' would be a category within a department.
*   **Brand**: This level specifies the manufacturer of the product.

This structure allows for a clear and consistent way to categorize all sellable product variants.
