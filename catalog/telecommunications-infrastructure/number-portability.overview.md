# Number Portability Overview

Number Portability, also known as Local Number Portability (LNP) or Mobile Number Portability (MNP), is a telecommunications capability that enables customers to retain their active phone number when switching service carriers. This regulatory-mandated capability allows subscribers to change providers without having to change their existing phone number.

## Aliases

This concept is also referred to by the following terms, which all refer to the same customer capability:
*   Local Number Portability (LNP)
*   Mobile Number Portability (MNP)
*   Porting

## Key Features & Process

The core function of Number Portability is to allow customers to keep their phone number when they transition between different telecommunication carriers. The process is managed by frontline care agents, who handle the necessary steps through a defined validation window before the provision changes are finalized.
