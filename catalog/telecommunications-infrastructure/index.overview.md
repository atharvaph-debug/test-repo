# Telecommunications Infrastructure

Metadata models, identifiers, and parameters used to configure, route, and optimize core telecom network operations.

| Path | Title | Type | Description |
|------|-------|------|-------------|
| catalog/telecommunications-infrastructure/access-point-name | Access Point Name | file | Metadata that identifies the target packet data network, selects the gateway, and determines policy parameters for data sessions. |
| catalog/telecommunications-infrastructure/international-mobile-subscriber-identity | International Mobile Subscriber Identity | file | The globally unique subscriber identifier provisioned onto a SIM card that acts as the primary join key for subscriber-level network records and log files. |
| catalog/telecommunications-infrastructure/quality-of-service | Quality of Service | file | Network traffic prioritization mechanisms configured against performance targets like latency, packet loss, and throughput constraints. |
| catalog/telecommunications-infrastructure/voice-over-lte | Voice over LTE | file | Packet-based voice communication services routed over LTE data networks via IP Multimedia Subsystems. |
