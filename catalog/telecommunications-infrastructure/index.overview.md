# Telecommunications Infrastructure

Core identifiers, routing protocols, and operational targets for mobile network and subscriber management.

| Path | Title | Type | Description |
|------|-------|------|-------------|
| catalog/telecommunications-infrastructure/access-point-name | Access Point Name | file | An identifier presented by a mobile device to route data sessions through specific packet data gateways and networks. |
| catalog/telecommunications-infrastructure/international-mobile-subscriber-identity | International Mobile Subscriber Identity | file | A globally unique subscriber identifier provisioned onto a SIM card that acts as the core authentication credential and anchor for subscriber services. |
| catalog/telecommunications-infrastructure/number-portability | Number Portability | file | The process and regulatory capability allowing a customer to retain their existing phone number when changing carriers. |
| catalog/telecommunications-infrastructure/voice-over-lte | Voice over LTE | file | A technology that routes real-time voice calls as IP packets over the LTE data network via the IP Multimedia Subsystem (IMS). |
