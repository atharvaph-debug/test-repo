# Financial and Regulatory Metadata

Metadata definitions and tracking mechanisms for treasury operations, credit risk, compliance, and regulatory reporting.

| Path | Title | Type | Description |
|------|-------|------|-------------|
| catalog/financial-and-regulatory-metadata/credit-risk-and-kyc-metadata | Credit Risk and KYC Metadata | file | Customer risk profiles distinguishing default probabilities from money laundering and financial-crime risk ratings. |
| catalog/financial-and-regulatory-metadata/liquidity-coverage-ratio-rules | Liquidity Coverage Ratio Rules | file | Regulatory balance-sheet and treasury metric measuring high-quality liquid assets against a 30-day net cash outflow stress scenario. |
| catalog/financial-and-regulatory-metadata/metadata-compliance-auditor | Metadata Compliance Auditor | file | Audits corporate data and transactional metadata against compliance policies, financial controls, and corporate expense guidelines. |
| catalog/financial-and-regulatory-metadata/net-interest-margin-metric | Net Interest Margin Metric | file | A core profitability metric measuring the net interest income generated per dollar of interest-earning assets. |
