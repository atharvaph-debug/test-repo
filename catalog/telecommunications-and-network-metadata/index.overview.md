# Telecommunications and Network Metadata

Identifiers, routing pathways, and operational parameters managing telecommunication sessions and customer identifiers.

| Path | Title | Type | Description |
|------|-------|------|-------------|
| catalog/telecommunications-and-network-metadata/access-point-name | Access Point Name | file | The routing configuration and gateway identifier presented by a cellular device to connect to a specific packet data network. |
| catalog/telecommunications-and-network-metadata/international-mobile-subscriber-identity | International Mobile Subscriber Identity | file | A globally unique subscriber identifier provisioned on SIM cards and transmitted for home operator authentication. |
| catalog/telecommunications-and-network-metadata/voice-over-lte | Voice over LTE | file | Voice communication service carried as packet data over LTE networks, highly dependent on QoS policies to maintain call quality. |
