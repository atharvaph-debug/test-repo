# International Mobile Subscriber Identity Overview

The International Mobile Subscriber Identity (IMSI), also known as IMSI, is a globally unique subscriber identifier provisioned on SIM cards and transmitted by cellular devices. It serves as a core metadata identifier within telecommunications networks, primarily for subscriber identity and authentication.

## Key Roles and Functionality

The IMSI plays a critical role in network operations:
*   **Subscriber Identity and Authentication**: It serves to answer the fundamental identity question: "Who is this subscriber?". A subscriber must be authenticated via IMSI before any session can be established.
*   **Network Authentication Protocol**: When a device connects to a visited partner network, the IMSI is read to identify the subscriber's home operator. This enables the visited network to signal the home operator for subscriber authentication and to determine billing and settlement rates, as outlined in Roaming Partner Agreements.
*   **Subscriber Activation Prerequisite**: Every SIM card is provisioned with an IMSI, making it an essential metadata component for a subscriber profile to become usable on the network. It functions alongside the Access Point Name (APN) to enable device access to services.
