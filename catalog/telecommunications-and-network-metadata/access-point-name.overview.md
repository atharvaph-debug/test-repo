# Access Point Name Overview

An Access Point Name (APN), also referred to as `apn`, is a critical metadata component in telecommunication networks. It represents the routing configuration and gateway identifier presented by a cellular device to connect to a specific packet data network (PDN). Its core role is to answer the fundamental question: "What network/service is this session for?"

## Key Features and Role

The APN serves as an identifier that a device presents to the network to indicate which packet data network (PDN) it needs to reach. It directs the core network on which gateway to route a data session through, functioning as a routing mechanism.

For a subscriber profile to become usable on the network, it requires two distinct metadata components: an identity provisioned on the physical SIM card (International Mobile Subscriber Identity or IMSI) and a configured data profile (APN) that enables the device to access services.

APNs include various types, such as public-internet APNs, as well as internal IMS APNs specifically utilized for voice signaling.
