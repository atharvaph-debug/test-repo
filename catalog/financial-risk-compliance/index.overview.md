# Financial Risk & Compliance

Core risk scoring, treasury parameters, and regulatory compliance workflows within financial systems.

| Path | Title | Type | Description |
|------|-------|------|-------------|
| catalog/financial-risk-compliance/anti-money-laundering | Anti-Money Laundering | file | Risk-based transaction and behavioral monitoring programs used to detect deviations from established customer baselines and report suspicious activities. |
| catalog/financial-risk-compliance/credit-risk-score | Credit Risk Score | file | A quantified estimate of a borrower's likelihood of defaulting on financial obligations. |
| catalog/financial-risk-compliance/customer-lifetime-value | Customer Lifetime Value | file | The total net profit expected from a customer over their entire relationship, aligning marketing and financial metrics. |
| catalog/financial-risk-compliance/know-your-customer | Know Your Customer | file | The onboarding and continuous verification process used to establish customer identity, beneficial ownership, and financial-crime risk profiles. |
| catalog/financial-risk-compliance/liquidity-coverage-ratio | Liquidity Coverage Ratio | file | A Basel III regulatory metric measuring the proportion of high-quality liquid assets held by a financial institution to meet short-term cash outflows. |
| catalog/financial-risk-compliance/net-interest-margin | Net Interest Margin | file | A core balance-sheet profitability metric managed by Treasury that measures net interest income relative to average interest-earning assets. |
| catalog/financial-risk-compliance/suspicious-activity-report | Suspicious Activity Report | file | The regulatory output filed when financial crime investigations confirm reasonable suspicion of illegal activity. |
