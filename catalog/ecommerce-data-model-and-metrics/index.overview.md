# eCommerce Data Model & Metrics

Analytical schemas, performance metrics, and transaction identifiers representing standard operations of the retail warehouse.

| Path | Title | Type | Description |
|------|-------|------|-------------|
| catalog/ecommerce-data-model-and-metrics/customer-lifetime-value | Customer Lifetime Value | file | The net profit projection generated by a customer throughout their entire relationship timeline. |
| catalog/ecommerce-data-model-and-metrics/number-portability | Number Portability | file | The capability and administrative process enabling telecom subscribers to retain phone numbers when transitioning across service carriers. |
