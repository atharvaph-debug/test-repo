# Number Portability Overview

Number Portability refers to the capability and administrative process that allows telecommunication subscribers to keep their existing phone numbers when they switch between service carriers. This feature is crucial in the telecom domain, enabling customers to retain their contact information despite changing providers.

## Aliases and Standardization

Number Portability is known by several interchangeable terms across operations. These include:
*   **Porting**
*   **LNP** (Local Number Portability)
*   **MNP** (Mobile Number Portability)

For consistency in documentation and reporting, it is preferred to use the term **"Number Portability"** over "LNP" or "MNP" when referring to this capability.
