# Financial Metrics

Calculations and terminology associated with revenue, cost, and pricing.

| Path | Title | Type | Description |
|------|-------|------|-------------|
| catalog/financial-metrics/cost | Cost | file | The wholesale or landed price paid to suppliers, hidden from consumers. |
| catalog/financial-metrics/gross-margin | Gross Margin | file | Net revenue minus the product cost, evaluated both in currency value and as a percentage relative to net revenue. |
| catalog/financial-metrics/gross-revenue | Gross Revenue | file | The sum of the sale price for all non-cancelled order items. |
| catalog/financial-metrics/net-revenue | Net Revenue | file | Gross revenue minus the revenue generated from returned items. |
| catalog/financial-metrics/retail-price | Retail Price | file | The advertised list or catalog price shown to customers prior to any discounts. |
| catalog/financial-metrics/sale-price | Sale Price | file | The actual transaction price paid by the customer, serving as the source of truth for realized revenue. |
