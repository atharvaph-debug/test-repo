# Financial Metrics

Canonical mathematical formulations used for corporate financial reporting and transaction analysis.

| Path | Title | Type | Description |
|------|-------|------|-------------|
| catalog/financial-metrics/average-order-value | Average Order Value | file | The mean gross monetary value of a single transaction order calculated as total item sales prices divided by distinct order counts. |
| catalog/financial-metrics/gross-revenue | Gross Revenue | file | The total sum of sale prices from sold order items, excluding transactions that were cancelled. |
| catalog/financial-metrics/net-revenue | Net Revenue | file | The sum of actual sales prices representing gross revenue minus returns, excluding both cancelled and returned items. |
| catalog/financial-metrics/units-sold | Units Sold | file | A count of total order lines representing successful product shipments that were not cancelled. |
