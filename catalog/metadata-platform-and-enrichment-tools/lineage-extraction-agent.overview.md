# Lineage Extraction Agent Overview

The Lineage Extraction Agent is an automated agent designed for metadata enrichment within data cataloging and discovery. It is built to parse and map structural data linkages, transformations, and relationships across complex data flows.

## Key Features

This agent plays a crucial role in understanding data flow and dependencies by:
*   **Parsing SQL Dialects**: It can interpret different SQL syntaxes to identify data transformations and sources.
*   **Analyzing Execution Logs**: The agent processes execution logs to capture the actual flow and operations performed on data.
*   **Building Lineage Maps**: Its primary output is an end-to-end map of data lineage, providing insights into where data originates, how it's transformed, and where it's used. This capability directly supports metadata enrichment efforts by providing crucial context for data assets.
