# Financial Performance Metrics

Metrics and KPIs used to assess corporate profitability and customer value.

| Path | Title | Type | Description |
|------|-------|------|-------------|
| catalog/financial-performance-metrics/customer-lifetime-value | Customer Lifetime Value | file | The total expected net profit generated over a customer's entire relationship, calculated as projected revenue minus cost-to-serve and retention spend. |
| catalog/financial-performance-metrics/net-interest-margin | Net Interest Margin | file | A balance sheet profitability metric expressing the net interest margin produced per dollar of interest-earning assets. |
