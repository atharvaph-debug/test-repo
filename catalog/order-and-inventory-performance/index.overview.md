# Order and Inventory Performance

Formulas and tracking metrics designed to evaluate order processing, customer purchasing, and warehouse velocity.

| Path | Title | Type | Description |
|------|-------|------|-------------|
| catalog/order-and-inventory-performance/average-days-in-inventory | Average Days in Inventory | file | The average duration an item spends in stock before being successfully sold. |
| catalog/order-and-inventory-performance/average-order-value | Average Order Value | file | Total gross revenue divided by the unique count of orders. |
| catalog/order-and-inventory-performance/return-rate | Return Rate | file | The share of non-cancelled order items that have been returned by the customer. |
| catalog/order-and-inventory-performance/sell-through-rate | Sell-Through Rate | file | The share of total warehouse inventory that has successfully been purchased. |
| catalog/order-and-inventory-performance/units-sold | Units Sold | file | The absolute count of all non-cancelled order item units. |
