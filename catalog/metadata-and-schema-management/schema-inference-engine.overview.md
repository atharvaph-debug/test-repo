# Schema Inference Engine Overview

The Schema Inference Engine (SIE) is an automated processing engine that scans incoming raw files to deduce and build structural schemas. This system, also known as `schema-enricher`, plays a crucial role in metadata enrichment by automatically extracting and cataloging data structures, supporting metadata enrichment and schema development.
