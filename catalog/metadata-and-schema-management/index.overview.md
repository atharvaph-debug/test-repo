# Metadata and Schema Management

Engines and catalogs responsible for discovering, standardizing, and generating rich conceptual schemas across enterprise platforms.

| Path | Title | Type | Description |
|------|-------|------|-------------|
| catalog/metadata-and-schema-management/schema-inference-engine | Schema Inference Engine | file | An automated processing engine that scans incoming raw files to deduce and build structural schemas. |
| catalog/metadata-and-schema-management/semantic-metadata-generator | Semantic Metadata Generator | file | An enrichment engine that translates technical operational schemas into standardized business taxonomies. |
| catalog/metadata-and-schema-management/unified-metadata-catalog | Unified Metadata Catalog | file | A centralized directory hosting technical definitions, schemas, and structural metadata across all operational systems. |
