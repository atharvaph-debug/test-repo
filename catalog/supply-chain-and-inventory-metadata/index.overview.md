# Supply Chain and Inventory Metadata

Hierarchical structures, planning rules, and facilities data managing products and supplier operations.

| Path | Title | Type | Description |
|------|-------|------|-------------|
| catalog/supply-chain-and-inventory-metadata/bill-of-materials | Bill of Materials | file | The structured definition of a finished product's physical components, sub-assemblies, and exact quantities. |
| catalog/supply-chain-and-inventory-metadata/distribution-center | Distribution Center | file | An operational logistics node that receives, stores, and fulfills order inventory between upstream suppliers and downstream demand. |
| catalog/supply-chain-and-inventory-metadata/reorder-point | Reorder Point | file | The safety stock and demand-based inventory level threshold that triggers automated replenishment processes. |
| catalog/supply-chain-and-inventory-metadata/stock-keeping-unit | Stock Keeping Unit | file | The primary internal identifier tracking a distinct, sellable product variant based on attributes like size, color, or packaging. |
