# Unified Catalog Platform Overview

The Unified Catalog Platform (also known as `ucp` or `unified-metadata-catalog`) is described as a centralized repository. Its primary function is to store enriched schemas, data lineage, and operational metadata, facilitating enterprise discovery.

## Key Features

The platform serves as a central hub for various types of metadata:
*   **Enriched Schemas:** Provides detailed and enhanced descriptions of data structures.
*   **Data Lineage:** Tracks the origin and transformation of data, showing its flow through various systems.
*   **Operational Metadata:** Contains information about the operation and management of data assets.

These capabilities are designed to support enterprise-wide data discovery.
