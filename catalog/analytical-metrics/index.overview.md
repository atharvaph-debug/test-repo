# Analytical Metrics

Canonical formulas and metrics definitions used for consistent business reporting.

| Path | Title | Type | Description |
|------|-------|------|-------------|
| catalog/analytical-metrics/average-order-value | Average Order Value | file | Gross revenue normalized by the distinct count of orders, excluding cancellations. |
| catalog/analytical-metrics/gross-revenue | Gross Revenue | file | The total sum of sale_price for all non-cancelled order items. |
| catalog/analytical-metrics/net-revenue | Net Revenue | file | The total sum of sale_price for order items excluding both cancelled and returned items. |
| catalog/analytical-metrics/return-rate | Return Rate | file | The proportion of non-cancelled items that were returned. |
| catalog/analytical-metrics/units-sold | Units Sold | file | The total count of distinct order items sold, excluding cancellations. |
