# Key Metrics

The primary Key Performance Indicators (KPIs) used to measure business performance.

| Path | Title | Type | Description |
|------|-------|------|-------------|
| catalog/key-metrics/average-days-in-inventory | Average Days in Inventory | file | The average number of days a product unit remains in stock before being sold. |
| catalog/key-metrics/average-order-value | Average Order Value | file | The average gross revenue generated per order, calculated as total gross revenue divided by the number of unique orders. |
| catalog/key-metrics/gross-margin-percentage | Gross Margin % | file | The gross margin expressed as a percentage of net revenue. |
| catalog/key-metrics/gross-margin | Gross Margin | file | The total profit from sales, calculated as the sum of sale_price minus cost for all net sales. |
| catalog/key-metrics/gross-revenue | Gross Revenue | file | The total revenue from all sold items before accounting for returns, calculated from order_items.sale_price. |
| catalog/key-metrics/net-revenue | Net Revenue | file | The total revenue after subtracting the value of returned items. |
| catalog/key-metrics/return-rate | Return Rate | file | The percentage of sold units that were subsequently returned by customers. |
| catalog/key-metrics/sell-through-rate | Sell-Through Rate | file | The percentage of inventory units that have been sold over a period of time. |
| catalog/key-metrics/units-sold | Units Sold | file | The total count of individual product units sold, excluding cancelled items. |
